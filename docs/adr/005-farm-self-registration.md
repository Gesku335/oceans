# ADR 005 — Саморегистрация ферм

## Контекст

OCEAN должен привлекать поставщиков (фермы). Процесс регистрации должен быть простым, но с
проверкой через Госуслуги/ЕСИА для юридической достоверности.

## Решение

Саморегистрация с верификацией через ЕСИА (Госуслуги). Админ может заблокировать/удалить
участника. Для ИП и физлиц — упрощённая регистрация с ручной модерацией.

## Рассмотренные варианты

| Вариант | Плюсы | Минусы |
|---------|-------|--------|
| Саморегистрация + ЕСИА | Масштабируемо, юридически чисто | Сложность интеграции |
| Ручное добавление админом | Контроль качества | Не масштабируемо |
| Без верификации | Просто | Мошенничество, юридические риски |

## Компромиссы

- ЕСИА — внешний сервис, может быть недоступен.
- Компенсация: интерфейс-адаптер, Mock для dev/тестов.

## Последствия

- Интерфейс `IdentityProvider` с методом verifyInn.
- Mock-реализация всегда возвращает success для тестовых ИНН.
- Статус верификации хранится в таблице suppliers.

## Когда пересматривать

После выбора конкретного провайдера (вопрос Q1).
