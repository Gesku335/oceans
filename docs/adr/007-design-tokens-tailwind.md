# ADR 007 — Дизайн-токены + Tailwind CSS

## Контекст

Нужна единая дизайн-система с поддержкой светлой и тёмной темы, контрастом WCAG AA, и
едиными отступами/радиусами. Интерфейс — русский, мобильный-first.

## Решение

CSS-переменные (дизайн-токены) в `packages/ui/tokens.css` + Tailwind CSS v4 с кастомными
токенами. Светлая/тёмная тема через `[data-theme]` и `prefers-color-scheme`. Шрифты:
Golos Text (UI) + Saira Stencil One (бренд), самохостные.

## Рассмотренные варианты

| Вариант | Плюсы | Минусы |
|---------|-------|--------|
| CSS-токены + Tailwind | Стандарт, автоматизация, dark mode | Кривая обучения |
| CSS-in-JS (styled-components) | Динамические стили | Runtime overhead, проблемы с SSR |
| Чистый CSS | Полный контроль | Ручная работа, нет utility-first |

## Компромиссы

- Tailwind-классы длинные в JSX.
- Компенсация: компоненты (`Button`, `Chip`, `StatusBadge`) инкапсулируют стили.

## Последствия

- Цвета только через `var(--token)` — eslint-hex-color-guard не пропустит HEX.
- Контраст-тест проверяет 12 пар ≥4.5:1.
- Фокус-кольцо через `:focus-visible` (§10.10).

## Когда пересматривать

При смене фреймворка стилей.
