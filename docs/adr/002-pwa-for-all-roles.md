# ADR 002 — PWA для всех ролей

## Контекст

Приложение используется поставщиками, заказчиками, курьерами и гостями. Гости входят по QR/NFC
метке — нужен мгновенный доступ без установки. Курьеры работают в поле с мобильного устройства.

## Решение

Progressive Web App (PWA) для всех ролей. Next.js App Router с Service Worker. Нативные
приложения (React Native/Expo) — после релиза R2.

## Рассмотренные варианты

| Вариант | Плюсы | Минусы |
|---------|-------|--------|
| PWA | Одна кодовая база, мгновенный QR/NFC-вход, нет ревью App Store | Ограниченные push на iOS, нет глубокой интеграции с ОС |
| Нативные приложения | Полная интеграция с ОС, push, геолокация | Две кодовые базы, ревью, установка |
| Гибрид (Capacitor) | Баланс | Сложность без преимуществ натива |

## Компромиссы

- Push-уведомления на iOS ограничены (Web Push с iOS 16.4+, но с ограничениями).
- Фоновая геолокация курьера менее надёжна, чем нативная.

## Последствия

- QR/NFC → URL → PWA открывается мгновенно.
- Для курьера: крупные тач-цели (48px минимум), офлайн-кэш маршрута.

## Когда пересматривать

Если курьерам нужна офлайн-работа и фоновая геолокация.
