# ADR 003 — PostgreSQL как единый источник правды

## Контекст

OCEAN хранит заказы, платежи, паспорта происхождения, рейтинги. Нужна надёжная система с
транзакциями и блокировками для предотвращения двойной продажи лотов и потери платежей.

## Решение

PostgreSQL 16 как единственная база данных. Без блокчейна. Компенсируем неизменяемость
аудит-логом и хеш-цепочкой записей паспорта.

## Рассмотренные варианты

| Вариант | Плюсы | Минусы |
|---------|-------|--------|
| PostgreSQL | Транзакции, блокировки, JSONB, зрелость | Нет криптографической неизменяемости |
| Блокчейн | Неизменяемость, верифицируемость | Сложность, стоимость, скорость, экосистема |
| PostgreSQL + Event Sourcing | Полная история | Чрезмерная сложность для масштаба |

## Компромиссы

- Нет криптографической неизменяемости записей паспорта.
- Компенсация: аудит-лог + хеш-цепочка (SHA-256 от предыдущей записи).

## Последствия

- Все денежные операции через леджер (двойная запись) в той же БД.
- Ночная сверка леджера как контроль целостности.

## Когда пересматривать

Если партнёры потребуют внешней верифицируемости паспортов.
