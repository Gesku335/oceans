# ADR 006 — Мультиязычное цифровое меню

## Контекст

Гости ресторанов просматривают меню на своём языке. Меню строится из товаров, которые
закупает заказчик через OCEAN. Нужна поддержка нескольких языков без хардкода.

## Решение

i18n-словари в JSON (русский по умолчанию, английский, китайский). Строки не хардкодятся.
Меню — отдельная страница PWA с QR/NFC-ссылкой.

## Рассмотренные варианты

| Вариант | Плюсы | Минусы |
|---------|-------|--------|
| i18n-словари | Гибкость, масштабируемость | Контроль переводов |
| Хардкод на одном языке | Простота | Не international-friendly |
| CMS для контента | Гибкость | Избыточно для меню |

## Компромиссы

- Качество переводов зависит от контрибьюторов.
- Компенсация: fallback на русский для отсутствующих ключей.

## Последствия

- `packages/shared/src/i18n/` с JSON-словарями.
- Все строки UI через функцию `t(key)`.
- Новые строки добавляются в словарь, не в код.

## Когда пересматривать

При добавлении нового языка.
