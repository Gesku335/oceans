# ADR 008 — Prisma ORM

## Контекст

OCEAN работает с PostgreSQL. Нужен ORM для миграций, типизированных запросов и seed-скриптов.

## Решение

Prisma ORM с PostgreSQL. Миграции через `prisma migrate`. Seed-скрипты для dev-данных.

## Рассмотренные варианты

| Вариант | Плюсы | Минусы |
|---------|-------|--------|
| Prisma | Типизация, миграции, seed, экосистема | Runtime overhead, генерация клиента |
| Drizzle | Лёгкий, SQL-like, быстрее | Меньше экосистема, миграции менее зрелые |
| TypeORM | Зрелый, декораторы | Устаревший API, баги |
| Raw SQL | Максимальный контроль | Ручная работа, нет типизации |

## Компромиссы

- Prisma-клиант увеличивает размер бандла API.
- Компенсация: tree-shaking, только нужные модели.

## Последствия

- `prisma/schema.prisma` с моделями для всех доменов.
- Миграции в `prisma/migrations/`.
- Seed-скрипт `prisma/seed.ts` для dev-данных.

## Когда пересматривать

Если производительность запросов станет проблемой (Drizzle).
